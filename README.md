# Health Monitor

Fundacao profissional em Next.js 15 com TypeScript, App Router, TailwindCSS, shadcn/ui, PWA, Supabase, Prisma, Zod e Recharts.

## Estrutura

```txt
apps/web
packages/shared
packages/db
```

## Primeiros passos

```bash
npm install
npm run dev
```

Copie `env.example` para `.env.local` dentro de `apps/web` e preencha as chaves antes de ligar Supabase e banco.
